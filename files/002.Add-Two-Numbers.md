# Problem 2: Add Two Numbers

## Problem Statement
You are given two **non-empty** linked lists representing two non-negative integers. The digits are stored in **reverse order**, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.

You may assume the two numbers do not contain any leading zero, except the number 0 itself.

**Example 1:**
```
Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: 342 + 465 = 807.
```

**Example 2:**
```
Input: l1 = [0], l2 = [0]
Output: [0]
```

**Example 3:**
```
Input: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]
```

**Constraints:**
- The number of nodes in each linked list is in the range [1, 100]
- 0 <= Node.val <= 9
- It is guaranteed that the list represents a number that does not have leading zeros

---

## Pattern Recognition
**Pattern:** Linked List + Math (Digit-by-Digit Addition)
**Difficulty:** Medium

This problem simulates manual addition with carry propagation, similar to how we add numbers on paper.

---

## Step-by-Step Explanation

### Understanding the Problem
1. Numbers are stored in reverse order in linked lists
2. We need to add them digit by digit from left to right (which is actually right to left in normal notation)
3. Handle carry when sum >= 10

### Algorithm
1. Initialize a dummy head for result list
2. Initialize carry = 0
3. Traverse both lists simultaneously:
   - Get values from current nodes (use 0 if node is null)
   - Calculate sum = val1 + val2 + carry
   - Update carry = sum / 10
   - Create new node with sum % 10
   - Move to next nodes
4. After traversal, if carry > 0, add one more node
5. Return dummy.next (skip dummy head)

## Visual Walkthrough

Example: l1 = [2,4,3], l2 = [5,6,4]
(Represents 342 + 465)

```
Step 1: 
  l1: 2 -> 4 -> 3
  l2: 5 -> 6 -> 4
  carry = 0
  sum = 2 + 5 + 0 = 7
  carry = 0
  result: 7

Step 2:
  l1: 4 -> 3
  l2: 6 -> 4
  carry = 0
  sum = 4 + 6 + 0 = 10
  carry = 1
  result: 7 -> 0

Step 3:
  l1: 3
  l2: 4
  carry = 1
  sum = 3 + 4 + 1 = 8
  carry = 0
  result: 7 -> 0 -> 8

Step 4:
  Both lists exhausted, carry = 0
  Final result: 7 -> 0 -> 8 (represents 807) ✓
```

Edge Case: l1 = [9,9,9,9], l2 = [9,9,9,9]
```
After processing all digits, carry = 1
Add extra node: result gets one more digit
Final: [8,9,9,9,0,0,0,1]
```

## Code Solutions

### Python Solution
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def addTwoNumbers(l1, l2):
    """
    Time Complexity: O(max(m, n)) where m, n are lengths of l1, l2
    Space Complexity: O(max(m, n)) for result list
    """
    dummy = ListNode(0)  # Dummy head
    current = dummy
    carry = 0
    
    while l1 or l2 or carry:
        # Get values (0 if node is None)
        val1 = l1.val if l1 else 0
        val2 = l2.val if l2 else 0
        
        # Calculate sum and carry
        total = val1 + val2 + carry
        carry = total // 10
        digit = total % 10
        
        # Create new node
        current.next = ListNode(digit)
        current = current.next
        
        # Move pointers
        if l1:
            l1 = l1.next
        if l2:
            l2 = l2.next
    
    return dummy.next

# Helper function to create linked list from array
def create_list(arr):
    dummy = ListNode(0)
    current = dummy
    for val in arr:
        current.next = ListNode(val)
        current = current.next
    return dummy.next

# Helper function to convert linked list to array
def list_to_array(head):
    result = []
    while head:
        result.append(head.val)
        head = head.next
    return result

# Test cases
l1 = create_list([2,4,3])
l2 = create_list([5,6,4])
print(list_to_array(addTwoNumbers(l1, l2)))  # [7,0,8]

l1 = create_list([0])
l2 = create_list([0])
print(list_to_array(addTwoNumbers(l1, l2)))  # [0]

l1 = create_list([9,9,9,9,9,9,9])
l2 = create_list([9,9,9,9])
print(list_to_array(addTwoNumbers(l1, l2)))  # [8,9,9,9,0,0,0,1]
```

### Java Solution
```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;
        int carry = 0;
        
        while (l1 != null || l2 != null || carry != 0) {
            int val1 = (l1 != null) ? l1.val : 0;
            int val2 = (l2 != null) ? l2.val : 0;
            
            int sum = val1 + val2 + carry;
            carry = sum / 10;
            int digit = sum % 10;
            
            current.next = new ListNode(digit);
            current = current.next;
            
            if (l1 != null) l1 = l1.next;
            if (l2 != null) l2 = l2.next;
        }
        
        return dummy.next;
    }
}
```

### JavaScript Solution
```javascript
function ListNode(val, next) {
    this.val = (val===undefined ? 0 : val)
    this.next = (next===undefined ? null : next)
}

function addTwoNumbers(l1, l2) {
    const dummy = new ListNode(0);
    let current = dummy;
    let carry = 0;
    
    while (l1 !== null || l2 !== null || carry !== 0) {
        const val1 = l1 ? l1.val : 0;
        const val2 = l2 ? l2.val : 0;
        
        const sum = val1 + val2 + carry;
        carry = Math.floor(sum / 10);
        const digit = sum % 10;
        
        current.next = new ListNode(digit);
        current = current.next;
        
        if (l1) l1 = l1.next;
        if (l2) l2 = l2.next;
    }
    
    return dummy.next;
}

// Helper functions
function createList(arr) {
    const dummy = new ListNode(0);
    let current = dummy;
    for (const val of arr) {
        current.next = new ListNode(val);
        current = current.next;
    }
    return dummy.next;
}

function listToArray(head) {
    const result = [];
    while (head) {
        result.push(head.val);
        head = head.next;
    }
    return result;
}

// Test cases
console.log(listToArray(addTwoNumbers(createList([2,4,3]), createList([5,6,4])))); // [7,0,8]
console.log(listToArray(addTwoNumbers(createList([0]), createList([0])))); // [0]
console.log(listToArray(addTwoNumbers(createList([9,9,9,9,9,9,9]), createList([9,9,9,9])))); // [8,9,9,9,0,0,0,1]
```

## Complexity Analysis

| Metric | Complexity | Explanation |
|--------|-----------|-------------|
| Time | O(max(m, n)) | Traverse both lists once |
| Space | O(max(m, n)) | Result list length |

Where m and n are the lengths of the two input linked lists.

**Note:** The result can be at most max(m, n) + 1 digits long (due to final carry).

## Common Mistakes

❌ **Mistake 1:** Forgetting to handle different lengths
```python
# WRONG - assumes both lists have same length
while l1 and l2:
    # Misses remaining nodes in longer list
```

✅ **Fix:** Use `while l1 or l2 or carry`

❌ **Mistake 2:** Forgetting the final carry
```python
# WRONG - doesn't check carry after loop
while l1 or l2:
    # ...
return dummy.next
```

✅ **Fix:** Include carry in loop condition or check after loop

❌ **Mistake 3:** Modifying input lists
```python
# WRONG - modifies l1 or l2 directly
l1.val = sum % 10
```

✅ **Fix:** Create new nodes for result

❌ **Mistake 4:** Incorrect carry calculation
```python
# WRONG
carry = sum % 10  # Should be division
digit = sum // 10
```

✅ **Fix:** carry = sum // 10, digit = sum % 10

## Reflection Questions

1. Why do we use a dummy head node? (Answer: Simplifies handling of first node)
2. What happens if one list is much longer than the other? (Answer: Continue with remaining nodes)
3. How would you modify this for forward-order storage? (Answer: Use stack or recursion)
