## 🧩 Problem Statement

Given an array of `intervals` where `intervals[i] = [start_i, end_i]`, merge all overlapping intervals, and return an array of the non-overlapping intervals that cover all the intervals in the input.

### 📝 Examples

**Example 1:**
```python
Input: intervals = [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]
Explanation: Since intervals [1,3] and [2,6] overlap, merge them into [1,6].
```

**Example 2:**
```python
Input: intervals = [[1,4],[4,5]]
Output: [[1,5]]
Explanation: Intervals [1,4] and [4,5] are considered overlapping.
```

**Example 3:**
```python
Input: intervals = [[4,7],[1,4]]
Output: [[1,7]]
```

**Example 4:**
```python
Input: intervals = [[1,4],[0,4]]
Output: [[0,4]]
```

### 🔍 Input/Output Types
- **Input:** 
  - `intervals`: List of intervals (`List[List[int]]`) - each interval is [start, end]
- **Output:** List of merged non-overlapping intervals (`List[List[int]]`)

## 🧠 Understanding the Problem

**What is this problem really asking?**

You need to combine all intervals that overlap or touch each other. Two intervals overlap if one starts before or at the same time the other ends.

**Key Points:**
- ✅ Intervals are inclusive on both ends
- ✅ [1,3] and [3,6] overlap (touching at boundary counts)
- ✅ Must sort intervals first by start time
- ⚠️ Output should be sorted by start time
- ⚠️ Empty input returns empty array

**Edge Cases:**
- Empty input array
- Single interval
- All intervals overlap
- No intervals overlap
- Intervals already sorted
- Intervals in reverse order

---

## 🧭 Recognizing the Pattern(s)

### 🎯 Primary Pattern: **Intervals + Sorting**

**Analogy:** Imagine you're scheduling meetings in a conference room. If one meeting ends at 3 PM and another starts at 2:30 PM, they conflict! You'd merge them into one longer booking. After sorting meetings by start time, you just need to check if each meeting overlaps with the previous one.

**Why This Pattern?**
- Sorting by start time allows single-pass processing
- Once sorted, we only need to compare adjacent intervals
- Greedy approach works: always extend current interval if possible

**Alternative Pattern:** Sweep Line Algorithm
- More complex but useful for related interval problems

## 🪜 High-Level Plan

### Strategy: Sort + Merge

1. **Sort intervals** by their start time
2. **Initialize result** with the first interval
3. **Iterate through remaining intervals**:
   - If current interval overlaps with last merged interval:
     - Merge by updating end time to max of both ends
   - Else:
     - Add current interval to result
4. **Return merged intervals**

### 📋 Pseudocode

```python
# Step 1: Handle edge case
if not intervals:
    return []

# Step 2: Sort by start time
intervals.sort(key=lambda x: x[0])

# Step 3: Initialize with first interval
merged = [intervals[0]]

# Step 4: Process remaining intervals
for current in intervals[1:]:
    last = merged[-1]
    
    # Check if overlapping (current starts before last ends)
    if current[0] <= last[1]:
        # Merge: update end time
        last[1] = max(last[1], current[1])
    else:
        # No overlap: add new interval
        merged.append(current)

return merged
```

## 💻 Complete Code Solutions

### Solution 1: Optimal - Sort + Single Pass

```python
from typing import List

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        """
        Merge overlapping intervals.
        
        Time Complexity: O(n log n) - sorting dominates
        Space Complexity: O(n) - for result array
        """
        if not intervals:
            return []
        
        # Sort intervals by start time
        intervals.sort(key=lambda x: x[0])
        
        merged = [intervals[0]]
        
        for current in intervals[1:]:
            last = merged[-1]
            
            # If current interval overlaps with last merged interval
            if current[0] <= last[1]:
                # Merge by extending end time
                last[1] = max(last[1], current[1])
            else:
                # No overlap, add as new interval
                merged.append(current)
        
        return merged
```

### Solution 2: Alternative - In-place Modification

```python
from typing import List

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        """
        Merge intervals with modified input array.
        More space efficient but modifies input.
        """
        if not intervals:
            return []
        
        intervals.sort(key=lambda x: x[0])
        
        write_idx = 0
        
        for read_idx in range(1, len(intervals)):
            if intervals[read_idx][0] <= intervals[write_idx][1]:
                # Overlap: merge by updating end time
                intervals[write_idx][1] = max(
                    intervals[write_idx][1], 
                    intervals[read_idx][1]
                )
            else:
                # No overlap: move to next position
                write_idx += 1
                intervals[write_idx] = intervals[read_idx]
        
        return intervals[:write_idx + 1]
```

### Java Solution

```java
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals.length == 0) {
            return new int[0][];
        }
        
        // Sort by start time
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        
        List<int[]> merged = new ArrayList<>();
        merged.add(intervals[0]);
        
        for (int i = 1; i < intervals.length; i++) {
            int[] last = merged.get(merged.size() - 1);
            int[] current = intervals[i];
            
            // If overlapping, merge
            if (current[0] <= last[1]) {
                last[1] = Math.max(last[1], current[1]);
            } else {
                merged.add(current);
            }
        }
        
        return merged.toArray(new int[merged.size()][]);
    }
}
```

### JavaScript Solution

```javascript
/**
 * @param {number[][]} intervals
 * @return {number[][]}
 */
var merge = function(intervals) {
    if (intervals.length === 0) return [];
    
    // Sort by start time
    intervals.sort((a, b) => a[0] - b[0]);
    
    const merged = [intervals[0]];
    
    for (let i = 1; i < intervals.length; i++) {
        const last = merged[merged.length - 1];
        const current = intervals[i];
        
        // If overlapping, merge
        if (current[0] <= last[1]) {
            last[1] = Math.max(last[1], current[1]);
        } else {
            merged.push(current);
        }
    }
    
    return merged;
};
```

```
current = [8,10]
last = [1,6]

Add: merged = [[1,6], [8,10]]
```

```
current = [15,18]
last = [8,10]
Check: 15 <= 10? NO → No overlap
Add: merged = [[1,6], [8,10], [15,18]]
```
