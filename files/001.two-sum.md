# 1. Two Sum

**Difficulty:** Easy  
**Pattern:** Array / Hash Map

## Problem Statement

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

### Examples

**Input:** `nums = [2,7,11,15], target = 9`
**Output:** `[0,1]`
**Explanation:** nums[0] + nums[1] == 9

### Constraints
- 2 <= nums.length <= 10^4
- -10^9 <= nums[i] <= 10^9

---

## Step-by-Step Solution

### Intuition
We need to find two numbers that sum to target. Instead of checking every pair (O(n^2)), we can store visited numbers in a hash map. For each number, we check if (target - current) exists in the map.

### Algorithm Walkthrough
1. Create an empty hash map to store value -> index.
2. Iterate through the array with index i and value num.
3. Calculate complement = target - num.
4. If complement exists in the map, return [map[complement], i].
5. Otherwise, add num and its index i to the map.
6. If no solution found (though problem guarantees one), return empty.

### Visual Example
Let's trace with `nums = [3,4,5,1,2]` (for Check if Array Is Sorted):
- i=0: 3 vs 4 (OK)
- i=1: 4 vs 5 (OK)
- i=2: 5 vs 1 (Drop! count=1)
- i=3: 1 vs 2 (OK)
- i=4: 2 vs 3 (Wrap around, OK)
- Total drops = 1 → Return True

## Code Solutions

### Python
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}  # value -> index
        
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
        return []
```

### Java
```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> seen = new HashMap<>();
        
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (seen.containsKey(complement)) {
                return new int[] { seen.get(complement), i };
            }
            seen.put(nums[i], i);
        }
        return new int[] {};
    }
}
```

### JavaScript
```javascript
/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number[]}
 */
var twoSum = function(nums, target) {
    const seen = new Map(); // value -> index
    
    for (let i = 0; i < nums.length; i++) {
        const complement = target - nums[i];
        if (seen.has(complement)) {
            return [seen.get(complement), i];
        }
        seen.set(nums[i], i);
    }
    return [];
};
```

## Complexity Analysis

- **Time Complexity:** O(N) - We traverse the array exactly once.
- **Space Complexity:** O(1) for the rotation check (or O(N) for Two Sum hash map).

## Key Takeaways
- Use modulo arithmetic `(i + 1) % n` to handle circular array checks elegantly.
- Early exit optimization: Stop as soon as the condition is violated.
- Hash maps are powerful for reducing O(N^2) problems to O(N) when looking for pairs.
